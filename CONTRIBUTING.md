# Contributing

Please open an issue describing the problem before proposing a large change. Small fixes and documentation improvements can go directly to a pull request.

For bugs, include the Forever build, addon version, steps to reproduce, expected behavior, actual behavior, and any Lua error. Redact character names and other identifying details from pasted reports.

Run the test and build commands in the main README. Tests simulate the client; please distinguish simulated checks from actual in-game verification. Update the relevant tests when behavior changes.

English is the primary documentation language. Translations live in `docs/README.<language>.md`. Keep installation paths, slash commands, version information, limitations, and language-navigation links consistent. Add translated instructions without claiming support for a game locale that has not been verified.
